---
name: Stable scenario references
description: Preserve public scenario identifiers when refreshing industry content.
---

Treat public scenario identifiers as durable references when revising the industry library. Editorial or product-accuracy updates should not rename them.

**Why:** Saved customer discussions and existing public links refer to the same scenario IDs. Refreshing scenario wording must not break an architect's saved selection or an older link.

**How to apply:** Preserve IDs for existing scenarios during content reviews. If a scenario truly must be retired or replaced, plan an explicit reference migration or an unavailable-scenario state rather than silently substituting a different scenario.
