The Outbound Dialers lab is for Zendesk Contact Center Platform Architects conducting live customer demonstrations, not for operating real campaigns.

**Why:** The user requested an executive-grade educational experience with fictional customers and explicitly prohibited real calls, messages, campaign creation, AWS mutations, and customer notifications.

**How to apply:** Keep new scenarios and controls simulation-only unless a later explicit request changes that scope. A campaign builder or notification preview must not silently become a live integration.

Distinguish illustrative pacing, conceptual Zendesk extensions, custom consent/suppression integrations, organization policies, and documented native AWS capabilities.

**Why:** The user requires technical credibility without invented AWS algorithms, Zendesk features, or automatic regulatory-compliance guarantees.

**How to apply:** Verify new technical claims against current official documentation, link the sources, qualify legal requirements independently, and only advance the displayed review date after an actual review.
